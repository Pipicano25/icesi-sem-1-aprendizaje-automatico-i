# Aprendizaje Automático I

**ICESI · Máster en Inteligencia Artificial Aplicada**

Fundamentos del aprendizaje automático: regresión lineal, normalización, regularización (L1/L2/Elastic Net) y primeros modelos de clasificación, con prácticas desarrolladas en Jupyter.

## Contenido

| Carpeta | Descripción |
|---|---|
| `Unidad 1` – `Unidad 5` | Material y notebooks por unidad |
| `Exercise` | Laboratorios y ejercicios prácticos |
| `Final` | Prácticas y entregas finales |
| `Classes` | Material de clase |
| `Documentation` | Libros y referencias (ISLR, ISLP) |
| `Recursos` | Material complementario |
| `Presentacion` | Diapositivas del curso |
| `Quiz` | Evaluaciones |

## Requisitos

- Python 3
- `numpy`, `pandas`, `matplotlib`, `scikit-learn`
